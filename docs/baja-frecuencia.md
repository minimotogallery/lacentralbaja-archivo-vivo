Promesa editorial: el correo llega; la obra ocurre donde estés.

Una entrega mensual prevista. Cada número propone un tema, una pieza de lectura de unos tres minutos, una partitura realizable con recursos cotidianos y una pregunta de retorno. La agenda ocupa un único bloque final, «Desde la nave».

La originalidad se trabaja en la continuidad: cada entrega escucha lo ocurrido con la anterior. No se presenta como un formato históricamente inédito. Las aportaciones de lectores solo se reproducen con autorización y crédito acordado; colaborar no implica suscribirse y suscribirse no implica ceder derechos sobre obras.
